# Lexift 1.0.2

- Caps Lock 상태 변경 시 화면 중앙에 ON / OFF 표시.
- 번체 및 주음부호: Caps + T로 번체 → 주음부호 → OFF 전환.
- 병음 성조: 설정에서 사용 선택. Caps + 1~4 지정, Caps + 0 해제.
- 성조 단축키는 상단 숫자키와 숫자패드 모두 지원 (Num Lock 무관).
- 일반 설정: 실행, 언어 스위칭, 발음 변환, 중국어 성조로 분류.
- 한글 입력 상태 제한 해제. 변환 시작 시 한글 입력으로 자동 전환.
- 네이티브 키보드 보조 프로그램과 읽기 전용 사전 인덱스로 메모리 절감.

성조 기능은 영문으로 입력한 병음에 적용합니다. 예: ke 입력 후 Caps + 3 → kě. 입력기는 변경하지 않습니다. 음절은 공백이나 작은따옴표로 구분합니다.
주음부호 출력에는 성조를 자동 부여하지 않습니다.

사용설명서: https://luttechan.github.io/lexift/guide/1.0.2/ko.html

번체 변환은 OpenCC의 s2tw를 사용합니다. OpenCC와 Rime 사전의 라이선스는 배포본에 동봉합니다.
