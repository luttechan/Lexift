# Lexift 1.0.3 검증 기록

## 수정

- Windows 기본 펼침 화살표의 최초 렌더링 지연을 자체 아이콘으로 대체.
- 최초 글꼴 조회와 입력기 선택창 구성을 시작 준비 단계에서 수행.
- 슬롯 이동과 삭제 시 전체 행을 다시 만들던 구조를 기존 행 재사용으로 변경. 이동 뒤 편집·삭제 대상도 검증.
- 네이티브 대화상자 구조체를 재사용하여 ctypes 포인터 타입 캐시 누수 차단.
- 사용자 사전 행 번호의 전체 조회 제거. 1,000개 제한에서 마지막 행을 잘못 편집하던 동작 차단.
- 숫자패드 성조 지원. Num Lock OFF 시 물리 키패드와 전용 방향키 구분.
- 후보 번호 선택과 성조 단축키 충돌 차단. IME 강제 전환 제거 및 입력칸/상위 창 구분 수정 포함.

## 표시 시간

Windows 로컬 검증 환경에서 실제 Qt 위젯을 화면에 노출하지 않고 렌더링했습니다. 각 언어는 별도 프로세스에서 측정했습니다. 슬롯 15개와 사용자 사전 1,000개를 사용했습니다. 아래 메뉴 값은 메인 창 구성이 끝난 뒤 화면을 전환하는 시간입니다. 메인 창 최초 구성 시간과 DWM 합성 시간은 포함하지 않습니다.

| 메뉴 | 9개 언어 첫 표시 범위 |
|---|---|
| 대시보드 | 3.6–4.4 ms |
| 입력기 슬롯 | 25.8–46.8 ms |
| 일반 설정 | 8.5–28.5 ms |
| 프로그램 정보 | 10.5–33.4 ms |
| 사용자 사전 | 37.0–53.2 ms |
| 실행 정보 | 18.9–39.3 ms |
| 트레이 메뉴 | 5.0–13.4 ms |

일반 메뉴 재진입과 설정 탭 전체 측정 범위: 2.1–27.9 ms.
메인 창 없이 시작한 경우의 첫 입력기 선택창: 57.4–70.6 ms.
최초 글꼴 준비: 1483.0–1579.1 ms. 이 시간은 메뉴 표시 시간에 포함하지 않았으며, 프로그램 준비 단계에 발생합니다.

초기 검증에서는 선택창 132 ms, 별도 메모리 시험의 사전 첫 표시 132 ms도 기록했습니다. 사전의 최초 CJK 글꼴 조회를 창 구성 단계로 이동한 뒤 최종 검증을 수행했습니다. 이전 결과는 `frozen-menu-matrix-initial.json`과 `frozen-menu-leaks-initial-1.0.3.json`에 보존했습니다. 운영체제 부하와 화면 배율에 따라 실제 표시 시간은 달라질 수 있습니다.

## 메모리

메뉴 10개 경로를 220회 반복하고 슬롯 이동 440회, 사전 행 삭제·추가 220회를 함께 수행했습니다. 준비 후 40회 시점과 220회 시점을 비교했습니다.

- 전용 커밋 증가: 0.000 MB
- 전용 작업 집합 증가: 0.062 MB
- 위젯 증가: 0
- 프로세스/GDI/USER 핸들 증가: 0 / 0 / 0
- 진단 작업 스레드 1개 재사용, 숨김 시 조회 중지, 창 폐기 후 스레드 종료 확인.

실제 본체와 단축키 보조 프로그램 합계의 대기 상태 작업 집합은 67.4 MB, 전용 작업 집합은 26.0 MB입니다. 공유 DLL을 포함하는 전체 작업 집합 60 MB 목표는 아직 충족하지 못했습니다. 작업 집합을 강제로 비우는 처리는 사용하지 않았습니다.

## 기능 점검

회귀 테스트 470개와 네이티브 입력 어댑터 79개 점검 통과. 실행 파일의 설정·사전·변환·성조·IME·메모리 검증과 9개 언어 메뉴 검증 통과. 언어 변경 후 이전 창 폐기, 단축키 중복 방지, 개별 사전 삭제, 드롭다운 스크롤 방지, 초기화 확인도 포함합니다.

외부 프로그램과 실제 키보드를 조작하지 않았습니다. 이 기록은 모든 외부 편집기와 장시간 사용에서 버그가 없음을 보장하지 않습니다. 네트워크 업데이트 서버의 응답 시간은 UI 표시 시간과 별개이며, 실제 업데이트 설치는 실행하지 않았습니다.
