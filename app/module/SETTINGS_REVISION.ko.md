# 설정 UI 수정 · Lexift 1.0.1

- 사용자 사전: 각 행 오른쪽의 삭제 버튼으로 해당 항목만 삭제합니다. 변경사항 저장을 누르면 적용됩니다.
- 일반 설정: 숨은 페이지를 미리 그리던 작업과 드롭다운의 불필요한 크기 계산을 제거했습니다.
- 단축키·언어: 닫힌 드롭다운 위에서 스크롤해도 선택 값이 바뀌지 않습니다.
- 표시 언어: 지원하는 9개 UI 언어별 확인 문구를 표시합니다. 취소하면 원래 선택으로 돌아갑니다.
- 기본값: 확인 후 단축키(Caps Lock + Q/A/C), 기능 사용, 한국어 표시, 시작 옵션, 입력기 슬롯과 사용자 사전을 초기화합니다. Windows 자동 실행은 꺼집니다. 취소 시 변경하지 않으며 저장 실패 시 기존 설정을 복구합니다.

전체 회귀 검사 419개 및 최종 소폭 보완 후 관련 검사 16개 통과. 이 수정은 기존 설정을 자동 초기화하지 않습니다.
