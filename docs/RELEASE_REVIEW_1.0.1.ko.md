| 구분 | 결과 |
|---|---|

| 실제 실행 파일 | 런타임·9개 언어 설정·기능/사전/알림음/크레딧·일본어·중국어 검사 통과 |

| 업데이트 | 실제 1.0.0→1.0.1 교체·기동·고의 실패 시 원본 복구·사용자 파일 보존 통과 |

## 성능

- 설정 화면 전환/그리기: 중앙값 8.29ms, 최대 29.16ms.
- 준비된 일본어 IME 첫 결과: 중앙값 63.5ms, 최대 92ms. 첫 요청은 275ms, 호스트 준비는 129ms로 별도 측정.
- 설정창 반복 검사 후 준비 구간을 제외한 private memory 증가: 0.79MiB. GDI 증가 0, USER 증가 0.

긴 문장의 전체 후보 병합은 여러 독음을 조회하므로 수 초가 걸릴 수 있습니다. 부분 결과를 먼저 표시하며 0.1초를 모든 입력의 완료 시간으로 보장하지 않습니다. 최초 폰트·IME 사전 준비 시간도 별도입니다.

## 범위와 제약

모든 동음이의어의 뜻을 자동 판별하는 기능은 아닙니다. 원래 독음과 조사 대안을 함께 유지하며 마지막 선택은 후보 확정에 따릅니다. 외부 프로그램을 직접 조작하는 테스트는 수행하지 않았습니다. Firefox는 IA2 경로 시험에 포함되지만 실제 Firefox 전체 입력 과정의 수동 검사를 완료했다고 주장하지 않습니다. 암호·읽기 전용 칸, 접근성을 제공하지 않는 입력란, 권한이 더 높은 프로그램의 기존 제약도 유지됩니다.
