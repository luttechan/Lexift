# Lexift 1.0.3

- 메뉴 지연 개선. 프로그램 정보의 실행 정보 펼침 지연 수정.
- 입력기 슬롯 이동과 삭제 시 기존 행 재사용.
- 네이티브 대화상자 구조체 누수 수정.
- 사용자 사전 행 번호를 표시할 때 전체 항목 조회 생략.
- Caps + 숫자패드 1~4로 성조 지정, Caps + 숫자패드 0으로 해제. Num Lock 상태와 무관하게 사용.
- 병음 성조는 영문 입력에 적용하며 IME를 강제로 변경하지 않음.

실행: `app/Lexift.exe` 또는 `run.bat`.
소스는 `source/`, 검증 결과는 `verification/`, 압축 배포본은 `release/`에 있습니다.

기존 설정과 사용자 사전은 유지됩니다.
