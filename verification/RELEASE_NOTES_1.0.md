# NOW WE ARE LEXIFT.

**일본어도 중국어도, 한글 발음으로.**

- 한글 발음으로 일본어·중국어 입력
- 사용자 사전, 기능별 ON/OFF와 단축키 설정
- 설정 화면 반응 속도와 후보 선택 개선

ZIP의 압축을 풀고 **Lexift.exe**를 실행하세요. Windows 10/11 x64용이며, 일본어 변환에는 Microsoft 일본어 IME가 필요합니다.
