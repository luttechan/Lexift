## English
- Faster menus and improved memory handling.
- Pinyin tones now support the numeric keypad, with Num Lock on or off.
- Type `ke`, then press Caps + 3 → `kě`. Your IME stays unchanged.

[Download for Windows](https://github.com/luttechan/Lexift/releases/download/v1.0.3/Lexift-1.0.3-Windows-x64.zip) / [User guide](https://luttechan.github.io/lexift/guide/1.0.3/en.html)

## 한국어
- 메뉴 지연과 메모리 증가 개선.
- 숫자패드 성조 지원. Num Lock 상태와 무관하게 사용.
- `ke` 입력 후 Caps + 3 → `kě`. 입력기는 바꾸지 않습니다.
