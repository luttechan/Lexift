# Lexift 1.0.1

More ways to type Japanese and Chinese pronunciations in Hangul.

- Better coverage for ambiguous sounds and Japanese loanwords
- Fixed long vowels and missing Chinese dictionary readings
- Multiple readings shown for Chinese polyphonic words

Unzip and run **Lexift.exe**. Windows 10/11 x64.
