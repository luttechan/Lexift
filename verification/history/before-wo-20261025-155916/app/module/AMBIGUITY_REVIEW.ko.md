# Lexift 1.0.1 발음 변환 점검

현재 엔진의 일본어 독음 규칙 전체와 중국어 사전 전체를 기준으로 검사했습니다. 한글에 없는 음성 차이와 성조까지 자동 복원한다는 뜻은 아닙니다. 서로 다른 발음이 같은 한글 표기로 들어오면 가능한 독음을 후보로 남깁니다.

## 일본어

| 구간 | 확인한 문제와 처리 |
|---|---|
| 청음·탁음 | 가/카, 다/타, 바/파를 함께 해석. 긴 입력에서도 전체를 같은 방식으로 읽은 대안을 유지 |
| 국어 표기의 합류 | 쓰의 ス/ツ, 어두 지의 ジ/ヂ/チ, 자·주·조의 ザ행/ジャ행/チャ행을 구분해 후보 생성 |
| 요음 | きゃ·しゃ·ちゃ·にゃ·ひゃ·みゃ·りゃ 등 기본 요음과 평음·경음 입력 검사 |
| 제·주·조 등 | 제를 ぜ로만 처리하던 경로에 じぇ 추가. 자·주·조에도 じゃ·じゅ·じょ 허용 |
| 외래음 | 파·피·푸·페·포에 ふぁ·ふぃ·ふ·ふぇ·ふぉ, 바행에 ゔ 계열 추가 |
| 디·듀 | 디는 でぃ, 듀는 でゅ. 기존 じゅ 해석도 대안으로 유지 |
| 위·웨·워 등 | うぃ·うぇ·うぉ·てぃ·とぅ·しぇ·ちぇ 및 フュ/ヴュ 검사 |
| 받침 | ㄴ/ㅁ/ㅇ의 ん, 폐쇄 받침의 っ 유지. ㄹ+ㄹ은 기존 독음과 받침을 합친 대안을 함께 제공 |
| ㄹ 연결 | 바이올린의 ばいおるりん 외에 ばいおりん 생성. 앞에서 글자 길이가 바뀌어 뒤쪽 대안 위치가 어긋나지 않도록 역순 적용 |
| じ/ぢ·ず/づ | 원래 독음을 유지하면서 표기 대안 제공. 縮む·ものづくり 등의 활용·합성어 검사 |
| 장음 | -를 모음별로 확장하고 おう/おお, えい/ええ, ー 대안을 제한된 범위에서 유지 |
| 장음의 범위 | コーヒー의 ー 보존이 같은 문장 내 다른 단어의 장음 확장을 막던 오류 수정 |
| 장음 중복 | 아리가토-/오하요-/도쿄우처럼 관용 표기에 이미 있는 장음이 다시 붙던 오류 수정 |
| 어간 보정 | 大きい의 おおき를 우선하되 応急 おうきゅう까지 같은 어간으로 바꾸지 않음 |
| 조사 | は/へ/を와 발음 わ/え/お 유지. 보쿠와처럼 끝에 온 조사와 따로 입력한 조사도 대안 생성 |
| 가나 직접 입력 | 직접 적은 가나의 정규화 결과 유지. 한글용 조사 보정을 직접 가나에 강제하지 않음 |
| 후보 제한 | 최대 16개 독음, 최대 200개 IME 후보 유지. 앞 독음이 200개를 채워도 나중 독음의 대표 후보가 들어갈 자리 확보 |

한글 완성형 11,172자는 정상적인 IME 키 문자열을 생성하는지 검사합니다. 국립국어원 가나 대조표의 기본 행·요음과 현대 외래음은 기대 가나가 실제 컴파일된 변환기의 대안에 남는지 별도로 검사합니다. 모든 한글 음절이 실제 일본어 단어라는 뜻은 아닙니다.

예: 쓰나미 → つなみ, 마쓰모토 → まつもと, 지바 → ちば, 주-스 → じゅうす, 파이루 → ふぁいる, 바이올린 → ばいおりん.

## 중국어

415종 사전 음절의 모든 생성 표기를 검사합니다. 각 음절을 성모·운모·활음·축약·설첨모음으로 분류하며 무조건적인 성모×운모 조합은 사용하지 않습니다.

| 구간 | 처리 |
|---|---|
| b/p/f·d/t·g/k | 한국어에서 겹치는 표기를 발음 비용과 사전 빈도로 정렬 |
| zhi/chi/shi·zi/ci/si | 특수 i와 일반 i를 구분. 지·치·시 같은 편의 입력도 낮은 발음 우선순위로 허용 |
| j/q/x·zh/ch/sh | 같은 한글에 여러 병음이 있으면 각 독음을 보존 |
| ü/u | ju/qu/xu/yu의 생략된 점 복원. n/l의 ü와 뒤쪽 u 구분 유지 |
| üan/ün | 췐·취엔·취안, 쉔·쉬엔, 쥔·췬·쉰 등 축약·펼친 표기 검사 |
| ian/iong | 첸·치엔, 슝·숑·시웅 등 표기 검사 |
| iu/ui/un | iou/uei/uen으로 분류. j/q/x의 un은 ün으로 먼저 분류 |
| 영성모 | y/w를 독립 성모처럼 붙이지 않고 원래 운모로 복원 |
| 비음 | n/ng를 별개로 유지 |
| 음절 경계 | 시안의 xi an과 시엔의 xian을 무조건 합치지 않음 |
| 탐색 누락 | 일반 발음 탐색에 잘린 실제 단어를 사전 접두사 경로로 복구 |
| 후보 다양성 | 여러 독음의 대표 단어가 한 독음의 빈도 높은 단어에 전부 밀리지 않도록 유지 |
| 다음자 | 谁의 shui/shei처럼 같은 한자의 여러 독음을 보존하고 후보 독음에 함께 표시 |

사전 독음 39,032종 각각에 대해 기본 표기·가장 애매한 표기·펼친 표기, 총 117,096건의 독음 도달성을 검사합니다. 가장 애매한 표기 전략에서 v1.0.0은 1,002종이 검색 전에 잘렸고, 수정 후 같은 검사의 누락은 0건입니다. 이 전략에서는 실제 후보와 독음 표시도 별도로 확인합니다. 같은 한자의 여러 독음은 중복 후보 행을 만들지 않습니다.

임의 사전을 넣어도 탐색이 무한히 늘지 않도록 일반 독음 32개와 사전 복구 독음 최대 96개로 제한합니다. 후보는 최대 20개이며, 39,032개의 사전 단어를 한꺼번에 표시한다는 뜻은 아닙니다.

## 남는 모호함

한글 표기만으로 성조, 청탁음, 장단음, 역사적 가나 표기, 같은 독음의 단어 뜻을 항상 결정할 수는 없습니다. 명확한 표기를 우선하고 대안을 함께 표시하는 방식입니다. 긴 문장에서 가능한 모든 조합을 나열하지 않으므로 카/타/파, 츠/쯔, 죠/쥬, 명시적인 모음이나 -처럼 구체적으로 입력하면 유리합니다. 자주 쓰는 이름·전문 용어는 사용자 사전으로 고정할 수 있습니다.

일본어의 실제 한자 후보는 설치된 Microsoft 일본어 IME 사전에 따라 달라집니다. 중국어는 기존 Rime 로컬 사전을 사용합니다. 이번 검증은 변환기·사전·자체 후보창·자체 TSF 호스트를 대상으로 하며 모든 외부 프로그램에서의 입력 호환성을 전수 검증한 것은 아닙니다.
