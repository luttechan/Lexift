# Lexift 1.0.1

일본어·중국어 발음 변환에서 놓치던 독음을 보완했습니다.

- 쓰나미·마쓰모토·지바, 제·주·파·듀 등의 여러 독음 지원
- 장음 중복과 다른 단어의 장음이 막히던 문제 수정
- 중국어에서 애매한 발음 때문에 실제 사전 단어가 검색 전에 사라지던 문제 수정
- 같은 한자의 여러 중국어 독음 표시

`run.bat` 또는 `app/Lexift.exe`를 실행하세요. 기존 Lexift가 실행 중이면 먼저 종료하세요.

`source/`는 소스, `docs/`는 사용 안내, `release/`는 배포 ZIP, `verification/`은 검사 결과입니다. 발음별 처리와 검사 범위는 `AMBIGUITY_REVIEW.ko.md`에 정리했습니다.
