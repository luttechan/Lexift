# 긴 명사구 뒤의 を

1.0.1의 조사 해석을 보완했습니다. 조사 を는 발음대로 한글 `오`를 입력해도 후보가 나오도록 처리합니다. 체언을 단어 목록에서 찾는 방식 대신, 입력한 경계와 뒤의 동사·활용·절 경계를 단서로 씁니다. 새로운 이름이나 긴 관형절이 붙은 명사구에도 같은 경로를 적용합니다.

## 바뀐 점

- 변환기 단위에서는 `혼 오 요미마스`처럼 명확한 띄어쓰기 경계가 주어지면 `ほんをよみます` 해석을 우선합니다. 실제 인라인 입력은 아래처럼 이어 쓴 한글 발음을 기준으로 검사합니다.
- `…카리타아타라시이혼오토모다치니와타시마시타`처럼 명사구 뒤에 다른 성분이 들어가도 `…かりたあたらしいほんをともだちにわたしました`를 별도로 보존합니다.
- `혼오요미나가라온가쿠오키키마스`처럼 여러 절에 を가 있어도 두 조사를 함께 적용한 독음을 남깁니다.
- 조사 후보를 청탁음·장음 대안과 따로 확보합니다. 긴 입력에서 は만 맞거나 を만 맞는 독음만 남고, 둘 다 맞는 문장이 잘리던 문제를 수정했습니다.
- 뒤 동사가 익숙한 활용형이면 단서를 강하게 적용합니다. 확신하기 어려운 경우에는 절마다 마지막으로 가능한 조사 위치를 대안으로 추가합니다.
- `오모이데오오모이다시마스 → おもいでをおもいだします`처럼 조사와 다음 단어의 첫 お도 구분해서 해석합니다.
- `아오이·오모이데·카오리·오노미치` 등의 내부 お와 사용자가 직접 입력한 일본어 독음은 유지합니다.

추측한 결과로 원문을 강제로 치환하지 않습니다. 원래 독음도 항상 남기고 실제 치환은 후보를 확정할 때 수행합니다. 전체 품사 분석기나 의미 분석기는 아니므로, 모든 문맥에서 명사와 조사를 완벽하게 구분한다고 보장하지 않습니다. 애매한 문장은 후보의 문장 독음과 표기를 확인해 선택하세요. 인라인 입력의 Space는 기존처럼 후보 확정 키입니다.

## 검증

- 긴 명사구, 두 개의 を, 다른 성분을 사이에 둔 목적어, 연속된 お, 명사 내부 お, 가나 직접 입력을 회귀 검사합니다.
- 최대 16개 독음과 원래 독음 유지 조건을 함께 검사합니다.
- 이전 실행 파일과 비교한 독음 순위: `verification/wo-particle-comparison.json`.
- 실제 Microsoft 일본어 IME 후보: `verification/wo-particle-ime.json`. 단순히 정규화 문자열이 있는지만 확인하지 않고 해당 전체 독음으로 한자와 を가 들어간 후보가 반환되는지 검사합니다.
- 최종 배포 실행 파일에 포함된 호스트의 검사는 `verification/wo-particle-packaged-ime.json`에 있습니다.

변환기 계산과 IME의 긴 문장 후보 생성은 별개입니다. 후보는 부분 결과부터 표시하며, 모든 독음의 최종 후보가 합쳐지는 시간은 문장 길이와 설치된 IME 상태에 따라 달라집니다. 측정 시간도 위 보고서에 기록합니다.
